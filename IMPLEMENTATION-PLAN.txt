IMPLEMENTATION PLAN — CREATED AFTER INSPECTING THE UPLOADS
==========================================================

INSPECTION FINDINGS
- EXAMPLE GAME BASICS.zip contains a modular Red Hot 8's build with separate audio,
  config, math, reel, render, UI, and game files.
- Its reel behavior is requestAnimationFrame based and has these distinct phases:
  acceleration, full-speed travel, per-reel stagger/extra travel, deceleration,
  configurable stop overshoot, return from overshoot, rebound, and settle pause.
- The example's exact button click and reel-stop files are usable for this build.
- The supplied SLOT UI is 1344x752 and contains three approximately 317px-wide reel
  windows inside a 958x576 reel area.
- All 14 supplied symbol images have transparency and can be used without editing.
- Supplied audio includes looping background music, bonus-land, and regular-win.
- A separate bonus-won sound was not present, so a timed Web Audio fanfare is used.

IMPLEMENTATION STEPS
1. Preserve supplied artwork and audio byte-for-byte in assets/.
2. Recreate only the example's reel movement model in a new animation module.
3. Build independent modules for math, outcomes, rendering, animation, audio, UI,
   editor, and game flow.
4. Implement five paylines and WILD substitution with placeholder pays.
5. Implement scattered WHEEL bonus, right-reel anticipation, eight-wheel pick,
   5–12 free spins, 2x wins, and same-amount retriggers.
6. Add regular, big, mega, pick, retrigger, and bonus-complete presentation flows.
7. Make every original UI control clickable with a precise press-mask effect.
8. Add local score submission/leaderboard and reset-credit behavior for the artwork's
   existing buttons.
9. Add a schema-driven editor with numeric controls, preview toggles, direct dragging,
   direct resizing, force-bonus testing, audio controls, and JSON import/export.
10. Add timestamp cache busting, service-worker cleanup, local launch scripts, and a
    README describing testing and extension points.
